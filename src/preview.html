What we ship next

This is a stand-in slide so you can try the overlay. Drag the timer. Pull the corner to resize. Start a countdown and let it run past zero to see the overtime pulse.

How this stays out of the way

  1. In Electron, click-through is on by default so a USB clicker still changes slides.
  2. The overlay is not focusable, so Page Down / arrow keys never land here.
  3. Hover the timer for start, presets, and ±1. Drag the clock to move. Pull the gold corner to resize.
